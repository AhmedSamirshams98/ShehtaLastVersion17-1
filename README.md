# 🚗 Shehta Trading Car Agency

A full-stack, production-ready Arabic car dealership platform built with Next.js, TypeScript, PostgreSQL, and Prisma ORM. The platform allows customers to browse vehicles, submit inquiries — while giving admins full control through a powerful dashboard.

🌐 **Live Site:** [shehtatrading.com](https://shehtatrading.com)

---

## ✨ Features

### Customer Side
- Browse vehicle listings with advanced search and filters
- View detailed car pages with images and specs
- Submit purchase inquiries and contact requests
- Fully responsive — optimized for mobile and desktop
- RTL Arabic-first design

### Admin Dashboard
- Manage all vehicle listings (add, edit, delete)
- View and respond to customer inquiries
- Manage orders and track their status
- Upload and manage vehicle images
- Role-based access control (admin vs public)

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 14, TypeScript, Tailwind CSS |
| Backend | Next.js API Routes, Node.js |
| Database | PostgreSQL |
| ORM | Prisma |
| Auth | JWT / Role-based access |
| Deployment | VPS |
